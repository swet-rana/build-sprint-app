# Health history design

The summary is a reading surface used by patients and doctors during a visit. Its visual anchor is a dated comparison sheet: paired results sit beneath each chart, with source links beside the evidence.

- Typeface: self-hosted Public Sans; 400 body, 500 labels, 600 headings, 700 brand.
- Palette: background #f1f5f7, paper #ffffff, text #233c48, secondary #526977, action #174e65, chart #176889, reference band #e6f0f1, above-range text #6e542c.
- Layout: maximum content width 1096px; two test columns on desktop, one below 760px. Original report links repeat beside each value.
- Type: title 34px desktop / 29px phone; summary title 25px / 21px; body 14–16px; source details 11–12px.
- Spacing: 32px summary inset desktop / 20px phone. Flat surfaces use borders, without shadows.
- Controls: navy print button, underlined source links, amber keyboard focus.
- Meaning: blue represents measured change, never improvement. Reference ranges come from sample reports. Fictional data is explicitly labelled.
- Print: A4 summary only; browser preview verified as one page.

Current scope is a sample screen. Upload, report reading, sign-in, and saving are not implemented.
