# Homepage realistic GIF icons

Four transparent looping GIFs replace the white circular badges. The background ribbons, navigation and report workflows remain unchanged. Reduced-motion users receive still PNGs.

Final assets: public/images/home-realistic-{storage,compare,orbit,thumb}.gif and corresponding -still.png files.
Source layers: design/home-icon-sources/. Regenerate with scripts/animate-home-realistic-icons.py using Pillow.
Generated through the built-in Image Generation tool, not a separate API.

Shared prompt: realistic studio-lit materials, white medical paper, translucent purple acrylic, glossy glass spheres, soft upper-left light, transparent backgrounds, no labels or real report data. No cartoon, text, pedestal or circle backing. Each object complete with a generous transparent margin.
